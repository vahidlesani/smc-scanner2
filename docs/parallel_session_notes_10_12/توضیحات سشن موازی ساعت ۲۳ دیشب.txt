## What was built in the `agent/geometry-fix` branch

**Unified Geometry Core** — `analysis/viva_geometry.py` (for both engines):
- All key patterns in the code: 16 main patterns + horizontal channel + open channel + pivot patterns (double top/bottom, head and shoulders ±, cup and handle ±) with neckline and measured target.
- Precise geometry: intersecting lines = invalid; apex and symmetry conditions (slope ratio 0.4–2.5); true parallelism via slope difference; rectangle requires both sides to be flat; entry side never changes the name.
- Entry base = the strongest valid directional movement, not just the last pivot.
- Event-based breakout cycle: first close-cross = event, sustained / fake (return within both sides) / retest / invalidation — `bars_ago` is calculated from the event itself.
- Pivot pattern doctrine: entry only via neckline break; breaking the opposite side = invalidation (the BTC 3D double-top case was correctly invalidated).
- r58 spike: an extreme wick only descends to the body if it's anomalous relative to other anchor wicks — legitimate touches are preserved.
- Stable time coordinates: lines are fitted in global coordinates; in tests, with history truncation / zoom, **the two lines remain strictly identical** (slope and intercept accurate to 1e-6).

**Two engines:** `engine_spot.py` (long-only, 4h–1w, downward breakout = alert) and `engine_perp.py` (single class with 4-brand adapter, long/short from both sides with nature gate and geometric stop).

**Two renderers:** spot is exactly in the CryptoCove reference style (lemon→sky gradient, green/red candles, black lag-accurate lines, green/red target box with arrow and label `delta (pct%) target`, price axis on the right, date axis) **without the CryptoCove mark** and with the VIVA brand; perpetual has the same new geometry in the current white/ink style (solid line up to LIVE, then dashed, labels only in the right margin, volume panel, brand badge).
