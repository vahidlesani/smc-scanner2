# VIVA-TLBREAK v1 scoring contract

Final score is independent from gates. Entry needs score >= 7 and all hard gates.

| component | max | notes |
|---|---:|---|
| Structure quality | 2.0 | pivot count, fit residual, pattern length |
| Breakout candle | 2.0 | close beyond line, body/range, close location |
| Retest/rejection | 2.0 | retest window, no deep re-entry, rejection pattern |
| Volume | 1.5 | score/confluence, not blind veto when venue data incomplete |
| MTF alignment | 1.5 | aligned full score; counter-trend requires stricter retest/volume |
| RSI | 1.0 | directional/non-extreme context |
| Key level bonus | +0.5 | HTF swing/round number confluence |
| Failed breakout penalty | -1.5 | recent same-level failed break |

Hard disqualifiers:
- pattern < required pivots/touches
- pattern length outside profile range
- over-extension before retest
- native-crypto/liquidity universe failure
- TP1 structural/measured RR < 1.5
