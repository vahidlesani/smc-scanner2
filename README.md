## 📊 استراتژی‌ها

### استراتژی‌های اصلی
| استراتژی | نماد | توضیح |
|----------|------|-------|
| SMC | 📊 | اسمارت مانی - اوردر بلاک + نقدینگی |
| RTM | 🔷 | Rally-Base-Drop و سایر الگوها |
| ICT | 💎 | OTE + Killzone + MSS |

### استراتژی‌های جدید
| استراتژی | نماد | توضیح |
|----------|------|-------|
| QM | 🔮 | کوآزیمودو - الگوی بازگشتی قوی |
| Engulfing | 🔥 | کندل پوششی صعودی/نزولی |
| PinBar | 📌 | پین بار / چکش / ستاره دنباله‌دار |
| FVG | 📐 | شکاف قیمتی (Fair Value Gap) |
| IFVG | 🔄 | معکوس شکاف قیمتی |
| FlipZone | 🔁 | تبدیل حمایت به مقاومت |
| Breakout | 💥 | شکست مقاومت/حمایت استاتیک |
| OrderBlock | 🧱 | ناحیه سفارشات بزرگ |
| CHoCH | ⚡ | تغییر ساختار بازار |
| Return Area | 🎯 | بازگشت به ناحیه عرضه/تقاضا |
