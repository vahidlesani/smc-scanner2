# ops/diag — harnessهای تشخیصی (R99q19)

ابزارهایی که برای «چرا این چارت غلط است» ساخته شده‌اند و از این پس داخلِ مخزن
می‌مانند (بیرونِ چتِ کاری). همه از ریشهٔ مخزن اجرا می‌شوند:

| ابزار | کار |
|---|---|
| `_chart_byid.py <SIGNAL_ID> [confirmed] [tag]` | هر زنجیرهٔ واقعی تولید را دوباره رندر می‌کند (ورودی: `signal_id`). |
| `_paint_audit.py` | هر خطی که چارت واقعاً «رنگ» می‌کند را با مختصات داده فهرست می‌کند (`Axes.plot` را می‌شمارد). |
| `_q19_proof.py [CODES…]` | برای هر کد: تازه‌سازی هندسه با کیت واقعی + refine خودِ ستاپ، رندر، و فهرست خطوط + `pattern_frame_bars`/`span`/`dropped`. |
| `_q19_audit.py [CODES…]` | مثل بالا، فقط دفترِ خطوط (قبل/بعد). |
| `_tc_raw.py SYM TF` | خروجی خامِ «دیتکتور» TC پیش از فیلترِ refine (تشخیص ول‌بودنِ خطوط). |
| `_tc_diag.py [CODES…]` | دامپِ metadata هر کد از `signal_candidates` (کلیدهای ترسیمی، `tc_dropped`، pattern_geo …). |
| `_spot_diag.py SYM:tf` | نردبانِ اسپات در برابر انجینِ دوم + زوم/پاکت. |
| `_spot_env.py` | پاکتِ اسپات (بلوکِ کندل) را با تریس `ylim` اندازه می‌گیرد. |
| `_pinval_audit.py` | دفترِ خطوط PINVAL. |

قوانینِ مربوطه: `docs/انضباط.md` بخش R99q19. بک‌فیلِ زنجیره‌های قدیمی:
`python3 ops/backfill_r99q19_patterns.py [days] [--dry]`.
